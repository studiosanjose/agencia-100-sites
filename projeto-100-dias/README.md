## 🗺️ As 4 Fases do Aprendizado

| Fase | Dias | Foco Técnico | Tipo de Projeto |
| :--- | :--- | :--- | :--- |
| **Fase 1** | **01 a 20** | Fundamentos HTML5, CSS Moderno, Glassmorphism, CRO & WhatsApp | Landing Pages One-Page de Alta Conversão |
| **Fase 2** | **21 a 50** | Multi-páginas, Formulários Dinâmicos, SEO Local & Acessibilidade | Sites Institucionais e Portais Corporativos |
| **Fase 3** | **51 a 80** | Filtros Dinâmicos, JavaScript Avançado, Catálogos & APIs | Garagens de Carros, Imobiliárias e Cardápios |
| **Fase 4** | **81 a 100** | E-commerce, Carrinho, Gateways de Pagamento (PIX/Cartão) & CMS | Lojas Virtuais Completas (WooCommerce / Headless) |

## 🛠️ Comandos Git Essenciais do Projeto

```bash
# 1. Verificar o que foi modificado
git status

# 2. Adicionar os arquivos ao pacote
git add .

# 3. Criar o commit padronizado
git commit -m "feat(dia-01): adiciona landing page premium para escritorio de advocacia"

# 4. Enviar para o GitHub e atualizar o site no ar
git push origin main
```

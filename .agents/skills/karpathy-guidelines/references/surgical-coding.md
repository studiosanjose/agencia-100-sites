# 🎯 Regras de Código Cirúrgico (Karpathy Style)

1. **Evite Dependências Desnecessárias**:
   - Se uma função utilitária de 5 linhas resolve o problema, não instale um pacote npm/composer de 2MB.
2. **Preserve os Padrões Existentes**:
   - Siga as convenções exatas de nomenclatura e estruturação já presentes no projeto.
3. **Diffs Limpos**:
   - Cada linha adicionada deve ter uma razão clara de existir.

# 🔍 SEO & Performance Optimization Skill

Esta skill orienta a implementação de SEO técnico completo para garantir indexação no Google, Rich Snippets e notas máximas no Lighthouse.

---

## 📋 Checklist de SEO Técnico

1. **Hierarquia Semântica**:
   - Um único `<h1>` por página, seguido por `<h2>` e `<h3>` ordenados logicamente.
2. **Schema.org JSON-LD**:
   - Inserir dados estruturados específicos para cada tipo de página (`Product` para e-commerce, `Article` para blog, `LocalBusiness` / `Organization` para agência).
3. **OpenGraph & Twitter Cards**:
   - Metadados completos para compartilhamento social (`og:title`, `og:description`, `og:image`, `twitter:card`).

# ⚛️ Frontend Mastery Skill

Esta skill traz as melhores práticas de desenvolvimento frontend moderno com React, Next.js e TypeScript.

---

## 🚀 Padrões Principais

1. **Next.js Server & Client Components**:
   - Mantenha buscas de dados e renderização inicial no servidor (RSC).
   - Use `'use client'` apenas em componentes interativos (formulários, modais, listeners de evento).
2. **Formulários Robustos com Validação**:
   - Utilize React Hook Form + Zod para validação síncrona/assíncrona de inputs.
3. **Imagens Otimizadas**:
   - Em Next.js, use sempre o componente `next/image` para geração automática de WebP/AVIF e prevenção de CLS.

Consulte os padrões de código em [references/react-next-patterns.md](./references/react-next-patterns.md).

# 💼 Client Communications Engine

Esta skill gera comunicações executivas, claras e persuasivas para clientes da agência digital.

---

## 📬 Padrões de Comunicação

1. **Status Report de Projeto (Semanal / Quinzenal)**:
   - O que foi entregue.
   - O que está em andamento.
   - O que precisamos do cliente (bloqueios / aprovações).
   - Próxima data de entrega.
2. **Tom de Voz**:
   - Profissional, prestativo, confiante e objetivo. Sem jargões técnicos incompreensíveis para leigos.

Consulte os modelos prontos em [references/agency-templates.md](./references/agency-templates.md).

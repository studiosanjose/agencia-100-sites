# 🎨 Web Design System Skill

Esta skill orienta a criação de interfaces modernas, impactantes e padronizadas para aplicações web e e-commerce.

---

## 💎 Diretrizes de Design

1. **Tokens de Design em Variáveis CSS**:
   - Defina cores, espaçamentos, tipografia, raios de borda e elevações em um único arquivo de tema (`tokens.css`).
2. **Glassmorphism & Profundidade**:
   - Combine fundos translúcidos com bordas sutis e `backdrop-filter: blur(12px)` para criar cartões sofisticados.
3. **Micro-interações**:
   - Adicione feedback tátil e visual ao passar o mouse (`hover`), focar (`focus-visible`) e clicar (`active`).

Consulte o catálogo de tokens prontos em [references/design-tokens.md](./references/design-tokens.md).

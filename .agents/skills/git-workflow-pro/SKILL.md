# 🌿 Git Workflow Pro Skill

Esta skill padroniza o ciclo de versionamento de código no Git usando o padrão Conventional Commits.

---

## 🏷️ Tipos de Commit

- `feat:` Nova funcionalidade ou recurso
- `fix:` Correção de bug
- `refactor:` Refatoração de código sem alterar comportamento externo
- `style:` Formatação visual, CSS, espaçamento
- `perf:` Melhoria de performance e velocidade
- `docs:` Documentação e comentários
- `chore:` Ajustes em dependências, configs e tooling

Consulte as regras detalhadas em [references/commit-standards.md](./references/commit-standards.md).
